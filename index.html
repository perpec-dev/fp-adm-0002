Exportar e manutenção

Os registros ficam no servidor e são os mesmos em qualquer aparelho. O que está nesta máquina é só uma cópia para funcionar sem internet — não é preciso fazer backup manual.

Porteiros cadastrados

—
Cadastre cada porteiro uma vez só: matrícula, nome completo, senha e assinatura. A matrícula é o login dele. O cadastro vale para todos os aparelhos — PC da portaria, celular e tablet usam o mesmo acesso.

Nenhuma ronda em andamento

Ao começar, o sistema já anota a hora e o seu nome. Durante o percurso, registre só o que estiver fora do normal. Se não achar nada, é só finalizar.
