# Prompt — Deck de treinamento dos porteiros

**Como usar:** abra o deck base da Perpec no Claude para PowerPoint e cole este arquivo
inteiro como instrução. Ele já traz o texto pronto de cada slide, então o modelo não precisa
inventar conteúdo — só montar e diagramar.

**São 20 slides. Não crie slides a mais.** Se um assunto não couber, corte texto, não
acrescente slide.

---

## 1. O que você vai montar

Um treinamento em slides para os **porteiros da Perpec** aprenderem a usar o sistema de
portaria: liberar entrada de veículo, registrar saída e fazer a ronda.

Use o **deck base da Perpec já aberto**. Não crie um tema novo, não mude master, cores nem
fontes do arquivo. Aproveite os layouts que já existem.

---

## 2. Quem vai assistir — a regra mais importante

Os porteiros **não têm alto nível de escolaridade** e a maioria nunca usou um sistema assim.
Muitos vão ver isto pela primeira vez num celular ou tablet, em pé, na guarita.

Isso manda em tudo neste deck:

- **Frase curta.** No máximo 12 palavras por linha.
- **Verbo no comando.** "Toque no botão vermelho", não "deve-se acionar o dispositivo".
- **Máximo 25 palavras de texto por slide**, sem contar títulos e legendas de print.
  Em slide de duas colunas, no máximo 15 palavras por coluna.
- **Nada de parágrafo.** Só frases soltas, listas de 3 a 5 itens, ou números de passo.
- **O visual manda, o texto confirma.** Se dá para mostrar com um print, uma seta ou um
  ícone, mostre — e use o texto só para dizer o que fazer.

### Palavras proibidas e o que usar no lugar

| Não escreva | Escreva |
|---|---|
| sincronizar, sincronização | mandar para o sistema |
| registro provisório | ainda não subiu |
| autenticação, credencial | matrícula e senha |
| offline / sem conectividade | sem internet |
| validar, validação | conferir |
| pack de observação | observação |
| módulo | parte do sistema |
| gerar relatório em PDF | gerar o relatório |
| interface, tela de login | tela de entrar |
| obrigatório preencher | precisa preencher |

Nunca use sigla sem explicar na hora. Nunca use inglês.

## 3. Estilo visual

Puxe do deck base. Só use estas referências se o base não definir:

- **Fonte:** Proxima Nova. Títulos em **Bold**, corpo em Regular.
  Título de slide 36–40 pt · texto 22–26 pt · legenda de print 14 pt.
  **Nunca abaixo de 20 pt** no corpo — vai ser lido em tela pequena.
- **Cores da Perpec:**

| Uso | Cor |
|---|---|
| Vermelho Perpec — ações principais, destaques | `#C0392B` |
| Vermelho escuro — apoio | `#961C13` |
| Grafite — títulos e faixas | `#1A1210` |
| Fundo claro | `#F2F1ED` |
| Branco — cartões | `#FFFFFF` |
| Cinza texto secundário | `#6A6760` |

- **Cores de situação** (estas têm significado fixo dentro do sistema, use sempre iguais):

| Cor | Significado | Hex |
|---|---|---|
| 🔵 Azul | Está dentro da fábrica | `#3D5AC0` |
| 🟢 Verde | Já saiu | `#2E7D32` |
| 🟡 Amarelo | Atenção / esperando internet | `#B7791F` |
| 🔴 Vermelho | Erro / falta preencher | `#C0392B` |

- **Muito espaço em branco.** Slide cheio assusta.
- **Numeração de passo:** círculo cheio vermelho `#C0392B` com o número em branco, grande.
- **Setas** vermelhas e grossas apontando o botão de que se está falando.
- **Marcador de parte:** como não há slide de divisória, os slides 3, 6, 13 e 18 levam uma
  tarja grafite fina no topo com o nome da parte, em branco e caixa alta.

---

## 4. Como marcar as áreas de print

Não invente telas nem desenhe mockups. Onde tiver print, **reserve a área** com um retângulo
de contorno tracejado cinza `#C5BDB5`, fundo `#F8F7F5`, cantos arredondados, e o texto do
marcador centralizado dentro, em cinza, 16 pt.

Formato do marcador, exatamente assim:

```
[PRINT 03]
Tela de começar turno
```

Cada slide diz abaixo qual print vai nele, em que posição e que tamanho. A lista completa
dos prints a tirar está na **seção 7**, para o instrutor capturar antes.

**Proporção:** os prints são de celular (retrato, mais ou menos 9:16). Reserve as áreas
sempre em pé, nunca deitadas, ou a imagem vai entrar distorcida.

**Slides com dois prints** (7, 8, 9, 15): duas áreas retrato lado a lado, do mesmo tamanho,
cada uma com o círculo numerado vermelho acima.

## 6. Checagem antes de entregar

- [ ] O deck tem **exatamente 20 slides**.
- [ ] Nenhum slide passa de 25 palavras de corpo de texto (15 por coluna, nos de duas colunas).
- [ ] Nenhuma fonte abaixo de 20 pt no corpo.
- [ ] Nenhuma palavra da lista de proibidas apareceu.
- [ ] Azul é sempre "está dentro" e verde é sempre "já saiu", em todo o deck.
- [ ] Toda área de print é retrato, com contorno tracejado e o marcador `[PRINT nn]`.
- [ ] Nos slides de dois prints, as duas áreas têm o mesmo tamanho.
- [ ] As tarjas de parte (slides 3, 6, 13, 18) são iguais entre si.
- [ ] Os botões desenhados usam o vermelho `#C0392B` com texto branco.
- [ ] O deck abre e fecha com a marca da Perpec.
